C. Aktivitas 1 — Eksperimen 10 + 20

Jangan jalankan terlebih dahulu. Prediksikan hasil:

let a = "10";
let b = "20";
console.log(a + b);
PertanyaanJawaban Kamu
Apa output program?1020
Mengapa hasil tersebut terjadi?Karena a dan b bertipe String (ditulis di dalam tanda kutip). Pada String, operator + bukan menjumlahkan, tetapi menggabungkan teks, sehingga "10" digabung "20" menjadi "1020".
Apakah a dan b bertipe Number?Tidak. Keduanya bertipe String.

Uji sekarang. Apakah prediksimu benar? Jelaskan.

Jawaban: Ya, prediksi saya benar. Setelah dijalankan, outputnya 1020, bukan 30, karena "10" dan "20" adalah String sehingga hanya digabung (konkatenasi), bukan dijumlahkan.

D. Aktivitas 2 — Menemukan Tipe Data

Jalankan:

let nama = "Asep";
let umur = 16;
console.log(typeof nama);
console.log(typeof umur);
VariabelPrediksiHasil typeofKesimpulan
namastringstringNilai di dalam tanda kutip adalah String.
umurnumbernumberAngka tanpa tanda kutip adalah Number.

Temuan: Apa perbedaan String dan Number berdasarkan eksperimenmu?

Jawaban: String adalah data teks yang ditulis dengan tanda kutip, dan operator + menggabungkannya ("10" + "20" = "1020"). Number adalah data angka tanpa tanda kutip yang bisa dihitung, dan operator + menjumlahkannya (10 + 20 = 30).

E. Aktivitas 3 — Konversi String menjadi Number

Perbaiki program agar menghasilkan 30. Gunakan Number():

let a = "10";
let b = "20";
let hasil = Number(a) + Number(b);
console.log(hasil);
Catat hasil program: 30

G. Tantangan — Program Hitung Nilai

Buat program dengan input nilai tugas, UTS, dan UAS. Konversikan semua input menggunakan Number(), lalu hitung rata-rata dengan rumus (tugas + UTS + UAS) / 3.

Algoritma saya:

  1. Minta input nilai tugas, UTS, dan UAS memakai prompt().
  2. Ubah ketiga input menjadi Number memakai Number().
  3. Hitung rata-rata dengan rumus (tugas + UTS + UAS) / 3 dan simpan di variabel.
  4. Tampilkan hasil rata-rata dengan console.log().
let tugas = Number(prompt("Nilai tugas: "));
let uts = Number(prompt("Nilai UTS: "));
let uas = Number(prompt("Nilai UAS: "));
let rata = (tugas + uts + uas) / 3;
console.log("Rata-rata = " + rata);

H. Think — Pair — Share

PertanyaanJawaban
Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung?Karena prompt() selalu menghasilkan String, walaupun yang diketik angka. Jika tidak dikonversi ke Number, operasi + hanya menggabungkan teks.
Apa perbedaan "10" dengan 10?"10" adalah String (teks), sedangkan 10 adalah Number (angka yang bisa dihitung).
Apa yang terjadi jika lupa Number()?Hasil perhitungan salah, misalnya "10" + "20" menjadi "1020" bukan 30. Operator *, -, dan / tetap bisa jalan karena JavaScript mengubahnya otomatis, tetapi + tidak.

Pair: Bandingkan jawaban dengan teman. Apakah sama? Mengapa bisa berbeda?

Jawaban: Inti jawabannya sama, hanya kalimatnya berbeda. Perbedaan bisa terjadi karena setiap orang memakai kata dan contoh yang berlainan, tetapi maksudnya tetap bahwa prompt() menghasilkan String sehingga harus diubah dengan Number().

Share: Sampaikan satu temuan penting kepada kelas.

Temuan penting: Hasil prompt() selalu String,jika ingin menjadi angka maka harus mengubahnya menjadi Number() sebelum dihitung agar hasil menjadi sesuai dengan yang di inginkan.
